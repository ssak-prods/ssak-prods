## What I've Shipped

> Not demos. Not tutorials. Running software, live clients, real usage.

| Project | What it does |
|:---|:---|
| **[Multica-Linux](https://github.com/ssak-prods/multica-linux)** | Autonomous multi-agent coding system — 24/7 on a Raspberry Pi 5. Send a spec via Telegram, return to finished code. 1,994 lines of custom Go. 29 tasks shipped autonomously. |
| **[PocketCMO](https://pocketcmo.io)** | AI-powered SaaS platform — live, German-market B2B clients. 14 parallel writing agents, adversarial quality gates, bilingual PDF delivery. Built and maintained solo. |
| **[ConfluxAI](https://marketplace.visualstudio.com/items?itemName=ConfluxAI.conflux-ai)** | VS Code extension — syncs team architectural decisions across IDEs in under 5 seconds. Custom MCP server, offline-first semantic search, live marketplace with real users. |
| **[Pi-Control MCP](https://github.com/ssak-prods/pi-control-mcp)** | One MCP connection, full Raspberry Pi 5 control — filesystem, shell, processes, and a running AI agent, all exposed over a Cloudflare Tunnel. Add the connector once and any AI gets tool-call access to the Pi: ChatGPT, Gemini, Perplexity, Claude, Cursor, Antigravity, Devin, Copilot. Plugin-first architecture: drop a `.js` file in `tools/`, restart, new capability appears everywhere. |
| **[TraderMan](https://github.com/ssak-prods/traderman)** | Zero-cost, zero-infra alert engine for Indian equities — scans NSE tickers for high-quality long entries, fires Telegram alerts, backtests locally on free data, and runs live on Google Apps Script. No broker API, no paid infra, no server. |
| **[WaterSafe](https://github.com/ssak-prods)** | ML × IoT water-quality monitoring system built for national-level competition. ESP32 + C++ edge firmware, real-time anomaly detection, Node.js telemetry dashboard. 2nd place at AIESEC Global Goals Hackathon 2026 (IIIT Hyderabad, ~70 teams). |
| **[OptoGuard](https://github.com/ssak-prods)** | Real-time object detection on ARM64 edge hardware — YOLOv8 + OpenCV, runs fully on-device on a Raspberry Pi 5 with no GPU. Inference pipeline purpose-built for CPU-only deployment. |
| **[SIH Bus ETA](https://github.com/ssak-prods/sihbus)** | Real-time city bus tracking system — FastAPI backend streams live GPS telemetry over WebSocket, React + Leaflet frontend renders moving buses on a live map, `/ingest_gps` endpoint accepts real hardware feeds. Built for Smart India Hackathon 2026. |
